### Taula
1. git init= Iniciar el directori al princpi
2. git push= Pujar les versions ya guardades del archiu
3. git pull= Atreu les ultimes version dels archius de git hub
4. git --version= Mostar la version de git que estas utilitzant en aquest moment
5. git remote add origin (URL git hub)= Vincules el teu directori de github

#### Incidencies d'avui
Avui no es pujaba al github l'archiu. Per solucionar aquest error hem fet un _git pull --rebase origin main_ per tornar l'archiu, desprès hem editat l'archiu per tornar a intentar la pujada i un cop hem fet _git push -u origin main_ l'archiu s'ha pujat al git hub perfectament.
